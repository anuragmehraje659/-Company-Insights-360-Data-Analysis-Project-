# 🧠 Company Insights 360° — Data Analysis Project  

A complete **end-to-end analytics project** integrating **Python**, **SQL**, and **Power BI**  
to deliver HR, Sales, and Performance insights for a simulated organization.

---

## 📊 Project Overview
This project demonstrates the full data analysis lifecycle:
1. **Data Extraction & Storage** — CSV files + SQLite database  
2. **Data Cleaning & Transformation** — using Python (pandas)  
3. **SQL Analysis** — Joins, Aggregations, KPIs  
4. **Visualization** — Power BI dashboards  
5. **Insights Generation** — KPIs, Profit trends, and HR analytics  

---

## 🧩 Tech Stack
- 🐍 Python (pandas, matplotlib, sqlite3)
- 💾 SQL (SQLite)
- 📊 Power BI
- 🧮 DAX (Custom measures for KPIs)

---

## 📈 Key Insights
- IT department achieved the highest average performance (4.6).  
- North region leads in total revenue, East has the best profit margin (21.8%).  
- Discounts above 15% reduce profit by ~20% on average.  
- Profit Margin %: 18.3% company-wide.
